## Decisions inside the unit

- **Trend inputs from the long series.** TSMOM's 252-session window and Donchian's channel come from the spliced
  series, so every target exists on 2016-01-04. Only the dev-window P&L is read; the long-sample TF P&L is never
  computed.
- **Weight timing.** w_t comes from state row t, the same decision as both components' targets, which is Gated's
  convention.
- **Per-configuration static.** Each configuration is paired with w = 0.5 at its own TF and vol scale, so the
  Donchian and vol-target variants are not compared with the TSMOM static.
- **R2 as a continuous P.** §6.5's "original headline" form; H3 used the > 0.5 gate.
- **B6_diff's first 62 sessions use w = 0.5,** registered and counted.
- **Look n = 12**: 9 configurations plus TSMOM, DC55 and the vol-managed buy-and-hold alone. R₀ is H1's stream, and
  the statics belong to their configurations.
- **Floor reading.** The blend net return must be ≥ the static's − 0.1 × |static's|, which is 0.9× when the static
  is positive.
